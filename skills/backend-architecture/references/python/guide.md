# Python 后端扩展入口

检查 pyproject.toml、锁文件、Python 版本和同步/异步栈。按业务模块组织 API、用例、领域和持久化；不强制每层抽象基类。

输入模型与 ORM 模型分开，区分可空和可缺省。类型注解不替代外部输入校验。数据库 Session/事务生命周期绑定用例或请求，不使用全局共享 Session；发生异常后明确回滚与释放。

异步端点避免直接运行阻塞数据库/网络操作；同步与异步驱动选择遵循项目实际栈。金额使用 Decimal 并定义序列化；异常在 API 边界映射，不能吞掉失败。验证资源关闭、事务回滚和授权。

实际使用 FastAPI、Django 或 SQLAlchemy 时在本目录新增对应指南，注明项目版本，并从 SKILL.md 按条件链接；不要同时加载所有框架。
