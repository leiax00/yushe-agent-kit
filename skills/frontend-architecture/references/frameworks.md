# React / Vue 适配

只阅读项目对应部分；具体 API 以项目锁定版本为准。

## React

组件渲染保持纯计算，派生值优先在渲染中计算，不用 effect 同步多个等价状态。effect 用于与外部系统同步并提供清理；依赖完整，避免用关闭 lint 掩盖闭包过期。列表 key 使用稳定业务身份。自定义 hook 封装可复用行为，不成为所有业务逻辑的容器。

保留项目已有请求缓存库，评估缓存失效与请求取消。只有测量或明确引用稳定性需求支持时引入 memo，避免机械包装。SSR 项目区分服务器和客户端边界，不把密钥放入客户端环境变量。

## Vue

props 保持单向传递，修改通过事件或明确状态接口。computed 表达派生值，watch 用于外部副作用并管理清理。组合式函数聚合可复用行为，避免隐式全局共享可变状态。使用响应式 API 时注意解构和引用语义，按实际 Vue 版本验证。

跨页面状态使用项目现有 store；局部表单不无条件上移。SSR 场景按请求隔离状态，避免模块级单例泄露不同用户数据。
