# 开始一个大任务

大任务 = 单一目标但需多步实现、跨模块或超过一两天量级。核心是**先拆解再动手**，每步可独立验证、可回退。

## 启动清单

1. **恢复上下文**：读任务涉及的模块文档、相关代码与既有 note，确认现状与约束；不凭印象假设。
2. **对齐目标**：用一两句话复述任务目标与完成标准，模糊处先问；完成标准 SHOULD 可验证（测试通过、文档更新等）。
3. **开分支**：`feat/<简短主题>`，从最新 `main` 拉；操作流程见[开分支与 worktree](branch-setup.md)。
4. **开 note**：在 `.agents/notes/proposed/feature/`（或对应 class）开一条决策记录，写清背景、方案、替代方案、验收标准，再动手；实现中随认知更新（生命周期规则见 yx-docs notes 参考）。
5. **拆解计划**：把任务拆成可一次会话完成并验证的步骤，建成 todo 列表；每完成一步简报结果。
6. **小步推进**：一步一主题一提交，保持每个提交可独立回退；不做与任务无关的顺手改动。

## 合入收尾

合入时一次完成：note 移入 `implemented/`、模块 `history.md` 追加演进、对外变化写入 `releases/unreleased.md`（四层分工的统一定义见 yx-docs）。
