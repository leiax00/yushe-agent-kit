# 前端模块与数据边界

按业务功能组织页面、局部组件、请求适配、状态和测试；基础组件库保持无业务依赖。路由页面负责流程组装，业务组件表达业务交互，基础组件表达通用视觉/输入能力。只有确实跨功能复用且语义一致时才提升到 shared。

前端 DTO 与显示模型可分离：日期、金额、枚举显示在适配层转换；未知枚举有安全兜底，不能把未知状态误显示为成功。服务端权限决定可执行操作，前端显隐只是体验控制。

避免组件直接散布 HTTP 地址、身份逻辑和响应解包。统一请求适配需保留取消、状态码、错误详情和追踪标识，不把所有失败压成空数组。

模块对外暴露稳定入口；避免业务 A 引用业务 B 的内部状态。样式、主题和响应式断点沿用项目设计系统，不在多个组件重复定义同一设计值。

新增目录必须有实际职责，不创建占位 service/utils/hooks 文件。重构以用户流程和可验证行为为边界。
