# 文档管理底线

完整的布局约定、模块文档模板、决策记录与变更记录规范由 `yx-docs` Skill 承载（涉及文档结构、查找、编写时加载）；本规则只保留强制底线：

1. 不在仓库根目录堆积散装 md 文件（MUST NOT，可能被 agent 工具误识别为技能入口）；文档按 `yx-docs` 的布局约定放置。
2. 移动或重命名文档时 MUST 同步更新所有引用链接。
3. 同一规则/事实只在一处定义，其他位置放链接。
4. 代码相关的描述与代码冲突时以代码为准，不凭记忆改写技术细节。
5. 中文为主，代码示例、专有名词保留英文；不冒充外部规范原文，未验证的内容不写成已验证。
6. 修改文档的提交用 `docs:` 前缀（见 git-workflow 规则）。
